# assets/

- `icons/` — generated app icons (don't edit by hand; run `tools/make_icons.py`).
- `icon-source.jpg` — **drop your cats photo here** and run
  `python3 tools/make_icons.py assets/icon-source.jpg` to use it as the app icon.

The couple/background photo is NOT stored here — set it inside the app under
**You → Settings → Home background** (it syncs across devices).
